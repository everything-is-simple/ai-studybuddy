## 1. 决策、目标与不可伪称的事实

用户已采用“个人版最小闭环”：当前只按既有 11 项高权重任务的 P1、P2、P3、P4、P5 顺序制定实施计划。P1 的唯一目标是为 `T02-R1` 和 `T02-R2` 设计**可在同一已批准时间窗口连续执行、但彼此完全独立签收**的最小受控只读接入。

- `T02-R1` 或 `T02-R2` 已实现、已执行、已签收或已有真实机器证据；
- 共同 trusted-approval/no-follow 合成接口已成为 production trust anchor，或 production verifier 已解除 fail-closed；
- 一次共同时间窗口等于一次共同授权，或任一任务的证据可替代另一任务；
- `T02`、Phase 3、备份/恢复、ACL 修复、用户电脑验收或生产上线完成。

P1 只压缩重复准备：一次工作树/制品身份核验、一次脱敏日志契约核验、一次用户约定时间窗口和一次最终汇总。R1 与 R2 必须各自拥有输入边界、执行前 Gate、固定失败码、脱敏证据、独立审查和完成结论。

## 3. 个人版授权模型与共同准备窗口

### 3.1 production verifier 保持不接入

现有 `verifyTrustedApproval` production 入口继续固定 fail-closed，且**不参与** P1 真实接入。没有 production trust anchor 时，后续实现不得绕过该入口、不得将测试专用 key 或普通本地配置当作 production 身份材料。

个人版的唯一授权来源是用户在本任务中对一次具体、可见、短时的操作作出的人工明确批准。它不是可持久化、可复用或可后台执行的机器授权。后续命令必须没有自动调度、重试、后台服务或保存真实批准记录的能力。

### 3.2 共享窗口只共享准备，不共享授权

每次真实运行之前，实施者只能在同一用户明确批准的时间窗口内做以下共同准备：

- 在 Gate 内存中核验执行脚本/包的**完整且未截断的 Git 对象 ID**和规则/契约版本；短哈希只能供人类脱敏显示，绝不作为授权或执行对象绑定；
- 确认所有输出仅为预定义脱敏字段；
- 显示 R1、R2 各自未满足即停止的 Gate；
- 为每项生成不同的、不可反推路径或用户名的短关联 ID。

窗口中仍必须有两份用户单项批准：

- **R1 批准**在 Gate 内存中只绑定：完整 Git 对象 ID、由其生成的 Git 已跟踪文件清单、一个用户明确指定的候选部署包根、该包**完整且规范化的 SHA-256 内容/树摘要**和窗口；所有绑定在安全读取前后复核，任一无法计算、匹配或复核均 fail-closed。短摘要绝不作为授权、包身份或执行对象绑定；
- **R2 批准**在 Gate 内存中只绑定：一个可证明为固定本地卷的明确本机安装实例身份、`config/data/logs/backups/tmp/models` 六个逻辑类别、窗口和只读 ACL 证据版本；运行前后必须通过同一 no-follow 句柄复核该安装实例与六类类别身份。机器、卷类型、安装实例或任一类别身份无法证明一致时 fail-closed；这些身份不得写入真实批准记录、日志或证据。

拒绝、超时、输入不一致、身份不一致、错误输出风险或任一 Gate 未通过时，只停止对应任务；另一项不会自动开始，也不会从失败项继承授权。

## 4. R1：真实秘密扫描的最小受控接入契约

### 4.1 允许输入

1. **仓库部分**：只能由 Git 已跟踪清单生成候选相对路径，且只在已批准的检出提交上运行。不得递归发现工作区文件，不能以仓库根目录作为隐式扫描根。
2. **候选部署包部分**：只能有一个用户在 R1 单项批准中精确指定的包根。实现先验证该根是被批准的单一候选且不含 reparse 风险，再读取显式、安全列举的包内候选；不能从“全部输出目录”、用户目录、临时目录或任意粘贴路径推断候选根。
3. **读取方式**：所有实际文件读取均走同一 no-follow 句柄契约；组件身份变化、reparse、类型异常、超限、访问错误或无法证明边界时 fail-closed。

任何未跟踪路径、`.env.local`、`production.env`、应用数据、日志、备份、模型、用户目录、环境变量、整个工作区和包根外路径均在内容读取前拒绝；拒绝报告不得给出其路径或文件名。

### 4.2 允许输出与 R1 签收

R1 只能输出：规则 ID、分类计数、扫描/跳过总数、不可反推 artifact ID、窗口 ID、契约版本和固定失败码。Gate 使用的完整 Git 对象 ID 与完整 SHA-256 只驻留本次内存核验，绝不输出；短 Git 哈希、短摘要和任何可反推包身份的值也不得输出。不得输出秘密值、完整配置行、环境变量、绝对路径、敏感相对文件名、原始命令、原始扫描输出、原始异常或完整 hash。

R1 的最终签收只能表述为“对已批准的 Git 已跟踪清单与一个批准候选包根的脱敏只读扫描结果”；任何命中、范围不明、输出净化失败或读取失败均不得表述为通过。

### 4.3 R1 固定失败码（后续实现必须保持脱敏）

| 代码                           | fail-closed 条件                                                       |
| ------------------------------ | ---------------------------------------------------------------------- |
| `P1_APPROVAL_MISSING`          | R1 单项人工批准、窗口或绑定字段缺失                                    |
| `P1_WINDOW_INVALID`            | 窗口过期、顺序错误或关联 ID 不匹配                                     |
| `R1_TRACKED_LIST_UNAVAILABLE`  | 无法取得精确 Git 已跟踪清单/提交身份                                   |
| `R1_UNTRACKED_OR_OUT_OF_SCOPE` | 输入不在已跟踪清单或批准包根内                                         |
| `R1_PACKAGE_IDENTITY_INVALID`  | 包根、完整规范化 SHA-256 内容/树摘要、类型或前后复核不能与单项批准绑定 |
| `R1_NOFOLLOW_RISK`             | reparse、同一句柄身份变化、类型/大小/访问风险                          |
| `R1_OUTPUT_REDACTION_FAILED`   | 输出模型不符合允许字段或可能泄露敏感信息                               |
| `R1_SCAN_INCOMPLETE`           | 任一允许对象无法安全扫描或结果无法完整汇总                             |

## 5. R2：Windows ACL 只读证据的最小受控接入契约

### 5.1 逻辑目录与拒绝策略

R2 的唯一范围为 `config`、`data`、`logs`、`backups`、`tmp`、`models` 六类逻辑目录。后续实现必须从经批准的安装实例派生这些类别；不得接受任意目录、仓库、worktree、包输出、用户根或环境变量作为 R2 目标。

每一类别必须逐组件使用同一 no-follow 安全句柄读取目录安全描述符。任何下列情形都必须拒绝整个 R2 结论，不可降级为“通过”：UNC、映射网络盘、非固定本地卷、reparse、未知主体、deny ACE、继承异常、有效访问未知、owner/DACL/SACL 读取不可证明、描述符大小超限或同一句柄身份变化。

R2 绝不执行 `Set-Acl`、`icacls` 写入、owner/DACL/SACL/继承变更、目录/文件创建、写探针、服务/计划任务控制、备份或恢复调用。

### 5.2 允许输出与 R2 签收

R2 每类目录只能输出固定逻辑类别、允许主体分类、继承/有效访问的固定状态、风险类别、短关联 ID、ACL 证据契约版本和固定失败码。允许主体分类限于：当前交互用户、当前用户计划任务、SYSTEM、Administrators、其他本地用户、未知主体、deny ACE、继承状态、有效访问未知。

不得输出完整用户名、SID、ACL 原文、owner 值、绝对/相对路径、ACE 原文、原始 PowerShell 输出或安全描述符字节。R2 最终签收只能是“六类已批准逻辑目录的脱敏只读 ACL 证据”；如发现风险，只能建议未来另批最小 ACL 修复，不能修复。

### 5.3 R2 固定失败码（后续实现必须保持脱敏）

| 代码                          | fail-closed 条件                               |
| ----------------------------- | ---------------------------------------------- |
| `P1_APPROVAL_MISSING`         | R2 单项人工批准、机器/类别/窗口绑定缺失        |
| `P1_WINDOW_INVALID`           | 窗口过期、顺序错误或关联 ID 不匹配             |
| `R2_LOGICAL_SCOPE_INVALID`    | 非六个固定逻辑类别，或目标未从批准安装实例派生 |
| `R2_UNC_OR_MAPPED_VOLUME`     | UNC、映射网络盘或远程卷                        |
| `R2_NONFIXED_VOLUME`          | 非固定本地卷或卷类型不可证明                   |
| `R2_NOFOLLOW_RISK`            | reparse、同一句柄身份变化或描述符读取风险      |
| `R2_UNKNOWN_PRINCIPAL`        | 未知主体、无法分类主体或 SID/名称解析不确定    |
| `R2_DENY_OR_INHERITANCE_RISK` | deny ACE、继承异常或 owner/DACL/SACL 状态异常  |
| `R2_EFFECTIVE_ACCESS_UNKNOWN` | 有效访问无法严格判定                           |
| `R2_OUTPUT_REDACTION_FAILED`  | 输出可能包含路径、身份或 ACL 原文              |
