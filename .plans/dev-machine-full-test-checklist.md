### T04-3: 恢复写入
```powershell

.\scripts\backup-data.ps1 -InstallRoot "$env:LOCALAPPDATA\AIStudyBuddy" -OutputRoot H:\test-backup

# 2. 停止服务
.\scripts\stop-production.ps1 -InstallRoot "$env:LOCALAPPDATA\AIStudyBuddy"

# 3. 恢复数据
.\scripts\restore-data.ps1 -InstallRoot "$env:LOCALAPPDATA\AIStudyBuddy" -BackupPath H:\test-backup\backup-*

# 4. 重启服务
.\scripts\start-production.ps1 -InstallRoot "$env:LOCALAPPDATA\AIStudyBuddy"
```
