## 2. T04-3 实现

`scripts/restore-data.ps1` 新增 `-EnableWrite` 受控写入，状态序列：

```
RESTORE_VALIDATED_NO_WRITE（默认 fail-closed）
→ STATE=PREWRITE_APPROVED
→ STATE=WRITERS_QUIESCED（PID 文件存在拒绝 RESTORE_PID_FILE_PRESENT / 端口监听拒绝 RESTORE_WRITERS_ACTIVE）
→ STATE=PRECHECK_PASSED（manifest 逐文件 hash 验证）
→ STATE=RECOVERY_POINT_VERIFIED（复制当前 data 到 backups/recovery-points/）
→ STATE=STAGING_WRITTEN_AND_VERIFIED（复制 payload，逐文件 hash 校验，清除只读属性）
→ STATE=POST_RESTORE_VERIFICATION（sqlite3 integrity_check）
→ RESTORE_COMPLETED
```

负向门禁：无 `-EnableWrite` → `RESTORE_VALIDATED_NO_WRITE`；PID 文件存在 → `RESTORE_PID_FILE_PRESENT`；服务监听 → `RESTORE_WRITERS_ACTIVE`。
