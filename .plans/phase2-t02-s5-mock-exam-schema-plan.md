## 4. 输入依赖与使用边界

### 4.1 考试范围

- 仅允许使用当前已确认考试的范围摘要、课程/考试归属和有效时间上下文。
- 未确认或已失效的考试不得触发正式模拟卷生成。
- 跨学期、跨课程或跨考试复用必须显式选择并保留来源；本计划不授权跨上下文自动混用。

### 4.2 知识模块

- 以当前学期、当前课程和当前考试上下文中的知识模块为候选覆盖范围。
- 模块仅作为来源与分析维度，不在本轮定义持久化字段、排序算法或覆盖比例实现。
- 模块来源应可追溯到已有结构化资料/知识模块摘要，不复制资料原文。

### 4.3 错题与薄弱点

- 只读取 S4 已确认或有证据支持的错题/薄弱点摘要及其关联知识模块。
- 不在 T02 内重新判断掌握状态、不重判 S3/S4 历史答案、不修改错题、错因、薄弱点或回流事实。
- S4 的隐私和最小必要数据边界继续有效；题干、完整答案和作答正文不能因为生成模拟考而自动进入 S6 或日志。

### 4.4 考试上下文

- 输入必须绑定学期、课程实例、考试目标和确认状态。
- 生成过程需要保留可审计的上下文引用和来源摘要，但本计划不设计具体 Schema 字段或 API 参数。
- 模拟考失败、来源不足、范围为空或 Provider 不可用时，不创建空卷，不伪造“已生成”事实。

## 5. 输出对象的概念责任

以下是后续设计必须覆盖的概念对象，不是本轮新增的数据库 Schema。

### 5.1 模拟卷（MockExam）

代表一次面向特定考试上下文的模拟试卷。概念上应包含题目顺序、题型、分值、难度、来源知识模块、考试范围引用和生成元数据。只保存最小可追溯来源，不复制资料原文；具体字段和持久化方式留待用户批准后的实现计划。

### 5.2 模拟考尝试（MockExamAttempt）

代表学生对某份模拟卷的一次限时作答。概念上覆盖开始、提交、批改、总分、正确率、耗时、超时状态、逐题作答引用和模块分析引用。T02 只规划责任边界，不实现计时、批改或 API。

### 5.3 成绩统计

代表一次模拟考尝试的确定性统计摘要，例如完成状态、得分、正确率、耗时和超时摘要。统计必须能区分生成失败、未开始、进行中、已提交和批改完成等事实状态，不能把建议或预测当成成绩事实。

### 5.4 模块分析

代表按知识模块聚合的模拟考表现摘要，用于后续复习决策。它应引用可追溯的尝试结果和模块来源，不得覆盖 S4 的掌握状态；具体分析算法、阈值和 UI 由后续批准任务决定。

## 6. 生成规则边界（仅概念与门禁计划）

- 生成输入必须受考试范围、知识模块和考试上下文约束，并可选择性读取错题/薄弱点摘要。
- 生成结果必须有来源引用、上下文归属和可解释的失败原因；来源不足时失败，不创建空卷或无来源题目。
- 生成应将 AI 视为可失败的可选能力；未配置、超时、熔断或返回不可解析结果时，保留可行动的人工复习入口，不伪造成功。
- 题目、答案、解析、作答与卡片正文属于学生本机学习数据，不应进入家长脱敏报告或普通日志。
- 统计与模块分析应基于已提交的尝试事实；预测、建议和薄弱点推断不得写回 S3/S4 历史事实。
- 生成幂等、重复提交、并发和版本策略属于后续实现审查项；本轮只登记为门禁问题，不写实现方案。
- 本轮不定义表结构、字段类型、迁移编号、API 路径、请求响应、Provider prompt 或 Worker 队列协议。

## 7. 与共同底座及 S3/S4 的复用关系

- 复用共同底座的学期库、课程/考试上下文、知识模块、AI Provider Router、配置与脱敏日志约束；不新增运行时配置，不读取或输出真实秘密。
- 复用 S3 已稳定的题目来源、练习事实、作答/提交/批改概念和客观题规则边界；不复制 S3 API，不把模拟考伪装成普通练习，不启动 S3 Worker。
- 复用 S4 的错题、证据、薄弱点和回流摘要作为可选输入；不重判、不反写、不删除 S4 历史事实。
- 模拟考产生的新事实应与 S3/S4 历史事实分开归属，并通过最小摘要/引用供后续复习或 S6 统计读取。
- 任何跨学期、跨课程、跨考试引用必须显式可审计；默认拒绝隐式混用。
