## 一、背景与痛点

大学生进入高校后处于"三不管"真空地带：

- 老师只管上课，课后不跟进
- 学校只管不出安全事故，不管学习过程
- 家长想管，但物理距离和信息断层让介入无从下手

学生一旦开始滑坡——翘课、失眠、孤立、迷失——没有任何系统能告诉家长。等家长知道的时候，已经是"大眼瞪小眼"。这是大学生家庭普遍面临的无声危机。

**产品定位**：不奢求大学能教学生多少，只帮学生在无人管的环境里建立一套自律地基。帮父母有存在感，能托底，不是监控，是细线连接。

### 1. 记录

课堂现场的原始素材留存。

| 功能 | 说明 |
|------|------|
| 课堂录音 | 手动触发或自动录制，本地压缩后上传 |
| 课堂录视频 | **可选功能，默认关闭**，用户可在设置中按需开启（仅录屏或摄像头） |
| 课堂笔记 | 手写识别 + 键盘输入，支持图片插入 |
| 链接资料保存 | 老师分享的链接一键存入课程资料库，自动抓取页面标题和摘要 |

**设计原则**：记录动作要极轻，上课前一键开始，下课后一键停止上传。

**原始素材保留策略（成本控制）**：录音/视频是"输入"不是"资产"——AI 整理生成结构化笔记后，原始音视频保留 **15 天**缓冲期后自动清理，转写文字稿和 AI 整理结果永久保留。视频功能默认关闭的原因：同等时长视频的存储量约为音频的 50 倍，会显著推高存储成本，具体清理机制见 ARCHITECTURE.md 7.9。

### 2. 整理

上传原始素材后，AI 自动处理，输出可用的学习材料。

**分类层级：学科（课程）→ 课次 → 整理结果**

- 所有素材和整理结果都按**课程**归档，一个课程就是一个学科
- 例如：「高等数学(下)」→ 第12课次「微积分基本定理」→ 结构化笔记 + 思维导图 + 重点高亮
- 学生打开App先看到课程列表，再进入某课程看课次，再看课次下的整理结果
- AI整理时注入课程上下文（课程名、本课次主题），让输出更精准
- 支持跨课次的知识点串联：AI可基于同一课程的多课次笔记，生成“章节总复习”思维导图

| 功能 | 说明 |
|------|------|
| AI结构化笔记 | 基于录音转写 + 手写笔记，按课程上下文生成章节化文档 |
| 思维导图 | 按课次提取知识点层级，输出带重点标注的思维导图 |
| 重点高亮 | 标注考试高频词、核心定义、重要公式 |
| 课程资料整合 | 将录音、笔记、链接资料整合进同一课次视图 |
| 跨课次串联 | 同课程多课次笔记可生成“章节总复习”思维导图（进阶功能） |

### 3. 写题

三个层次，贯穿平时学习到考前冲刺。

#### 3.1 平时练习
- 每章节结束后系统推送课堂练习
- 练习有时效（如 48 小时内完成），超时标记未完成
- 题型：选择、填空、简答，难度与课堂内容匹配
- AI 批改 + CoT 解析（学生提交后立即出批改结果和完整解题思路）

#### 3.2 老师作业
- 学生将老师布置的作业录入系统（拍照/手动输入），记录截止时间
- 完成后提交到系统，AI 负责批改和解析
- 老师不提供解析，系统一律由 AI 补上——读题→审题→解题思维链→最优解法
- 家长面板只看到：交了没、准时不准时

#### 3.3 考前真题解析（CoT 重生成）

学生上传历年期末真题后，AI 不直接给答案，而是还原完整解题思维链：

| 步骤 | 说明 |
|------|------|
| 读题 | 提取题目表层信息，复述题目结构 |
| 审题 | 判断题型、难度、考察方向 |
| 划重点 | 标注关键词、限定条件、陷阱词 |
| 找条件 | 梳理已知量、隐含条件、边界情况 |
| 初步构造思维链 | 列出多条可能解法路径 |
| 查找相关知识点 | 关联课本/考纲知识节点 |
| 剪枝错误路径 | 说明哪些路走不通，为什么 |
| 最终解析 | 保留最正确、最高效的解法，附评分要点 |

输出结果是学生能"看懂思考过程"的教学材料，而不是冷冰冰的答案。

#### 3.4 冲刺变题组卷

- 基于历年真题知识点分布，改数字/改情境/改问法生成新题
- 学生可自定义：复习科目、难度比例、题型比例、时长
- 倒计时限时考试，到时自动提交
- AI 批改 + CoT 解析：提交后立即出分、出完整解题思维链
- 系统记录完成时间、得分、薄弱知识点
- 家长面板只看到：完成状态和时间，不看分数和对错

#### 3.5 错题本

所有做题场景（平时练习、老师作业、真题解析、变题卷）的错题自动沉淀到错题本。

**自动收集：**
- 每次批改完成后，系统自动将错题入库，记录：原题、学生答案、正确答案、CoT解析、错因分类
- 错因分类由AI自动判断：知识点不熟悉 / 审题失误 / 计算错误 / 理解偏差 / 不会做

**艾宾浩斯间隔复习（核心机制）：**

做题不复习等于白做。系统基于艾宾浩斯遗忘曲线，自动安排每道错题的复习时间：

| 复习轮次 | 距首次做错 | 复习方式 |
|---------|----------|----------|
| 第1轮 | 1天后 | 原题重做 |
| 第2轮 | 2天后 | 原题重做 |
| 第3轮 | 4天后 | AI生成变题（改数字/改情境） |
| 第4轮 | 7天后 | AI生成变题 |
| 第5轮 | 15天后 | AI生成变题（更高难度） |
| 第6轮 | 30天后 | 综合检测 |

- **每日复习队列**：系统每天自动推送"今日待复习错题"，学生打开App就能看到
- **复习方式交替**：原题重做（巩固记忆）和变题练习（检验迁移能力）交替进行
- **掌握标准**：连续3次做对（含变题），标记为"已掌握"，移出复习队列
- **做错重置**：如果复习时又做错了，复习间隔重置回第1轮，重新开始
- **考前加速**：距考试2个月内，未掌握错题集中推送，不再等间隔

**变题练习（不只是重做原题）：**
- AI基于错题涉及的知识点，生成"换皮题"：考同一个知识点，但题目不同
- 变题方式：改数字、改情境、改问法、增加干扰条件
- 变题能检验学生是"记住了答案"还是"真正理解了"
- 变题难度可调：简单变体 → 综合变体 → 跨知识点融合题

**AI错因分析：**
- 按知识点汇总错题分布，找出最薄弱的章节
- 考前生成"错题复习报告"：哪些知识点错得多、复习了几轮、现在掌握了多少
- 家长面板不看到错题详情，只看到"本周复习了几道错题"

**设计原则：**
- 错题本不是惩罚工具，是帮助学生看到自己的进步
- 掌握一道就少一道，视觉上要有"清空感"
- **做题是输入，复习才是输出**——没有间隔复习的刷题等于零

### 4. 可见（家长视角）

家长与学生共享同一个空间，只读，不能修改任何内容。

**核心逻辑**：家长看的不是分数，不是对错，是——他有没有在做，有没有在坚持。任务量一直增加，完成时间一直有记录，这条时间线本身就是答案。

#### 家长面板：任务完成时间线

所有任务统一呈现，每条记录包含：任务名、截止时间、实际完成时间、状态。

| 任务类型 | 截止时间来源 | 状态标记 |
|---------|------------|---------|
| 课堂录音/笔记上传 | 系统按课次设定（如课后24小时） | 及时 / 迟交 / 未提交 |
| 平时章节练习 | 系统推送时设定（如48小时） | 及时 / 迟交 / 未提交 |
| 老师布置的作业 | 老师设定截止时间，必填 | 及时 / 迟交 / 未提交 |
| 期末真题解析（每套） | 考试前2个月系统自动预警，按进度分配 | 完成时间签名 |
| 变题模拟卷（每套） | 学生自定义或系统建议节点 | 完成时间签名 |

#### 考前预警机制（两阶段）

| 阶段 | 距考试 | 任务重心 |
|------|--------|----------|
| **预警期** | **2个月** | 系统自动触发预警，提醒学生上传历年真题，启动 CoT 解析生成（读题→审题→找条件→最终解析），先把知识点吃透 |
| **冲刺期** | **1个月** | 真题解析基本完成，转入集中刷变题模拟卷：按剩余天数自动分配每天几套限时模拟考，检验迁移能力和答题速度 |

- 按剩余天数自动分配任务量：预警期以真题解析为主，冲刺期以变题模拟卷为主，两阶段任务量按天数递减/递增平滑过渡
- 家长面板同步显示备考任务分配表和当前完成进度，且能看出当前处于"预警期"还是"冲刺期"

#### 家长看到的就是这一张表

- 今天/本周，哪些任务该做，做了没，几点做完的
- 工作量随时间增加的趋势（说明孩子在努力）
- 任何任务都有截止时间，没有模糊地带

#### 家长鼓励

- 家长可以对孩子的任何完成任务点一个“赞”（鼓励）
- 学生在App内能看到“爸爸/妈妈给你点了个赞”
- 不做评价，只表达关注——你做了，我看到了
- 这是家长和孩子之间唯一的双向互动点

**设计原则**：
- 家长只能看，不能修改
- 不显示题目内容和答案，只显示完成状态和时间
- 不做评判，只做呈现——他努力了，就够了

## 四、用户旅程

### 学生视角（一个普通学习日）

1. 上课前：打开 App，点击"开始记录"，自动录音
2. 课中：记手写/键盘笔记，保存老师发的链接
3. 下课后：点击"上传整理"，AI 在后台处理
4. 当天晚上：查看 AI 生成的笔记和思维导图，完成当天练习
5. 考前两个月：系统预警触发，开始上传历年真题、查看 CoT 解析；考前一个月起：集中刷变题模拟卷，冲刺训练

### 家长视角（每天一眼）

1. 打开共享空间，看任务完成时间线
2. 一眼扫过：今天该做的，做了没，几点做完的
3. 考前两个月：看备考任务分配表，今天完成了几套

## 五、核心设计原则

1. **学生有主体感**：复习科目、时长、节奏由学生自己定，系统只是工具
2. **家长视角温柔**：不看分数不看对错，只看有没有做、有没有坚持
3. **低摩擦记录**：录音/上传动作要极简，不能比不用这个软件更麻烦
4. **AI 是助手不是老师**：AI 整理笔记、生成题目、还原解题思维链，但不替代学生思考
5. **任务必须有截止时间**：所有任务——练习、作业、真题解析、变题卷——都有明确截止时间，没有模糊地带
6. **AI 全权负责批改和解析**：学生做的所有题（平时练习、老师作业、期末真题、变题卷），统一由 AI 批改 + 生成 CoT 解题思维链。老师不给解析的，系统补上
7. **家长不看对错**：AI 批改结果和分数只给学生看，家长面板只显示完成状态和时间

### 6.2 AI 能力层

**核心原则**：每个AI功能可独立配置模型，用户可自接入，不绑定单一厂商。

| AI功能 | 推荐默认方案 | 推荐理由 | 成本 |
|---------|------------|----------|------|
| 录音转文字 | **SenseVoice-Small**（阿里开源，自部署） | 中文CER 3%（Whisper是5%），234M参数，CPU可跑，自带情感识别 | 免费 |
| 录音转文字备选 | **FunASR + Paraformer**（阿里达摩院，自部署） | 完整pipeline（VAD+ASR+标点+说话人分离），生态最成熟 | 免费 |
| OCR识别 | **PaddleOCR**（百度开源，自部署） | 中文识别准确率97.3%，开源免费，Apache 2.0 | 免费 |
| 笔记结构化 | **DeepSeek V4-Pro** | 需要较强理解和结构化能力，性价比极高 | ¥0.44/¥0.87 每百万token |
| 思维导图生成 | **DeepSeek V4-Flash** | 简单结构化提取，不需要顶级模型 | ¥0.5/¥1 每百万token |
| 重点高亮 | **DeepSeek V4-Flash** | 关键词/定义提取，轻量任务 | ¥0.5/¥1 每百万token |
| AI出题 | **DeepSeek V3.2** | 中等推理能力，生成题目需要理解笔记内容 | ¥2/¥8 每百万token |
| CoT解析 | **DeepSeek R1** | 强推理能力，数学/编程题解析需要深度思维链 | ¥4/¥16 每百万token |
| AI批改 | **DeepSeek V4-Flash** | 简答评分+选择题匹配，轻量任务 | ¥0.5/¥1 每百万token |
| 变题组卷 | **DeepSeek V3.2** | 需理解题目结构并生成变体 | ¥2/¥8 每百万token |
| URL摘要 | **DeepSeek V4-Flash** | 轻量摘要任务 | ¥0.5/¥1 每百万token |

**对比参考**：GPT-4o 约 ¥50/百万token，Claude约 ¥100/百万token。国产模型便宜 10-150 倍。

### 6.3 用户可配置 AI 接口

系统提供一个 **AI配置页面**，用户可以自行接入AI服务：

- 支持 OpenAI兼容API格式（DeepSeek、Qwen、GLM、Kimi等国产模型全部支持）
- 用户可配置：API地址、API Key、模型名称
- **每个功能可单独配置不同的模型**
- 系统预设默认配置，用户不改也能用
- 配置示例：“笔记整理用DeepSeek，思维导图用Qwen-Plus，CoT解析用Kimi K2.6”

## 七、暂不实现的功能（明确排除）

以下功能在当前版本（v1.0）中**不做**，避免范围蔓延：

| 功能 | 不做的原因 |
|------|----------|

| 付费/会员体系 | 家庭自用工具，不考虑商业化 |
| 多语言国际化 | 当前只面向中文用户 |
| 离线AI处理 | 端侧算力不足，AI全部走服务端 |
| 手写笔记原笔迹渲染 | v1.0只做手写识别转文字，不做原笔迹展示 |

## 八、已确认决策

### 8.1 平台策略
- **移动端优先**：学生课堂场景以手机为主
- 技术栈：**React Native (Expo)**，跨平台移动端
- 家长查看面板后期可复用到 Web

### 8.2 第一个核心模块（记录 → 整理，先有素材再谈整理）
- **第一步：课堂录音**——记录模块是整个产品的入口，没有原始素材，AI 整理就没有加工对象
- **第二步：AI 整理**（录音转文字 → 结构化笔记 → 思维导图 → 重点高亮）——消费第一步产生的素材，是核心价值体现，AI 能力的展示窗口
- **手动文本输入是兜底路径，不是主路径**：极少数场景（如漏录、录音失败）可以直接粘贴文本跳过 ASR，直接进入笔记整理环节，但 MVP 的主线用户旅程是"录音→整理"，不是"手动输入→整理"

### 8.3 作业录入方式
- **两种都支持**：拍照识别为主，手动输入为辅
- 拍照识别：拍照后 OCR 提取文字，学生确认/修正后保存
- 手动输入：学生输入作业标题、内容描述、截止时间

### 8.4 考试时间录入
- **两种都支持**：
  - 手动填写：学生逐科录入考试日期
  - 学期初统一录入：开课时填入课程表和考试周时间，系统自动调度备考计划
- 系统根据考试时间自动倒推：真题解析分配、变题卷安排、每日备考任务

### 8.5 AI 服务配置策略
- **每个AI功能可独立配置模型**：笔记整理、思维导图、出题、CoT解析、批改等，各自可用不同模型
- **支持 OpenAI 兼容 API**：DeepSeek、Qwen、GLM、Kimi 等国产模型全部兼容
- **用户可自接入**：系统提供 AI 配置页面，用户填入自己的 API Key、API 地址、模型名
- **自部署免费方案**：录音转文字（SenseVoice/FunASR）和 OCR（PaddleOCR）优先自部署，不花API钱
- **设计原则**：天长地久都要用，成本必须可控。不用最贵的，用最合适的

### 8.6 AI Key 归属策略（混合方案，已确认）

回答"谁的 Key、谁付钱"这个关键问题：

| 阶段 | 方案 | 说明 |
|------|------|------|
| 新用户注册 | **系统提供试用额度** | 内置开发者的 Key，赠送每月固定调用次数（如 50 次），覆盖轻度使用（笔记整理+思维导图），零配置即可体验核心价值 |
| 试用额度用完 | **引导切换为用户自备 Key** | App 内弹出提示 + 跳转到"5 分钟注册 DeepSeek 教程"，用户填入自己的 API Key 后无限使用 |
| 用户已配置自己的 Key | **优先使用用户 Key，不再消耗系统额度** | Provider 解析顺序：用户配置 → 系统默认试用额度 → 拒绝调用并提示 |

**成本约束**：系统试用额度必须设置**硬性月度上限**（按空间/用户维度），超限后调用直接拒绝并提示切换 Key，不允许无限透支开发者账户。默认额度和上限的具体数值见 ARCHITECTURE.md AI Provider 配置章节。

**为什么不是纯自备 Key 或纯系统包揽**：
- 纯自备 Key：新用户第一次打开 App 就要去注册 DeepSeek 账号、生成 Key，门槛过高，"低摩擦"原则被破坏在第一步
- 纯系统包揽：作为个人项目没有商业模式支撑，一旦用户量增长，AI 费用由开发者个人承担会不可控
- 混合方案让新用户零门槛体验到 AI 整理的核心价值，重度使用者（备考冲刺期）自然过渡到自备 Key，成本责任随使用深度转移
